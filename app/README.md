# Folder app

Aplikasi Streamlit yang dijalankan lokal di PC stan.

- Halaman Warga: tanya jawab, pemeriksaan program, penyusun surat permohonan dan daftar berkas (Word).
- Halaman Kelurahan: antrean pengajuan, penanda tenggat dan kelompok rentan, tombol ubah status.

Diisi oleh koordinator dan PJ Jalur C. Cara menjalankan akan ditulis di sini setelah kerangka aplikasi dibuat.

Aplikasi membaca pengaturan dari file `.env` di folder utama repo (lihat `.env.example`).
